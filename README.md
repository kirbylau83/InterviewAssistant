# InterviewAssistant

Full-screen interview dashboard for mid-market and enterprise Account Executive interviews.

## Run

1. Open `src/index.html` in your browser.
2. Optional: press `F11` (or browser full screen) on your secondary monitor.

## Dashboard Sections

- Main Talking Points (largest section)
- Camera preview (small section)
- Q/A from interviewer
- Questions for interviewer
- Compact interview timer with presets (30/45/60 minutes)
